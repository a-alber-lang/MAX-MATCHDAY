MAX' MATCHDAY – PWA
=====================
Enthalten:
- index.html
- manifest.webmanifest
- sw.js
- icon.svg

Wichtig: Eine PWA muss über HTTPS (oder localhost) ausgeliefert werden.
Die Dateien daher auf einen HTTPS-Webhost hochladen. Danach in Chrome öffnen
und „App installieren“ / „Zum Startbildschirm hinzufügen“ wählen.
Version 0.1
